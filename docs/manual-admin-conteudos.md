# Manual do Usuário - Gestão de Conteúdos

## Introdução

Este manual tem o objetivo de orientar os usuários no uso da interface administrativa para gerenciamento de conteúdos do site. Com esta ferramenta, você pode atualizar estatísticas e textos de seções do site de forma simples e rápida.

## Acesso ao Sistema

1. Acesse a área administrativa pelo link `/admin/`
2. Realize o login com suas credenciais
3. No menu lateral, clique em **Conteúdos**

## Gestão de Estatísticas

As estatísticas são valores numéricos exibidos em várias páginas do site, como contador de títulos publicados, exemplares distribuídos etc.

### Visualizando estatísticas

Na aba "Estatísticas", você verá uma tabela com as seguintes informações:
- **ID**: Identificador único da estatística
- **Chave**: Identificador interno usado pelo sistema
- **Valor**: O valor numérico da estatística
- **Descrição**: Texto descritivo que aparece no site
- **Última Atualização**: Data e hora da última modificação
- **Ações**: Botões para editar a estatística

### Editando uma estatística

Para editar o valor de uma estatística:

1. Localize a estatística desejada na tabela
2. Altere o valor no campo de entrada
3. Clique no botão de confirmação (✓) para salvar

Observação: A chave não pode ser alterada, pois é utilizada pelo sistema para identificar cada estatística.

## Gestão de Textos de Seções

Os textos de seções são conteúdos textuais que aparecem em diferentes áreas do site, como textos introdutórios de páginas.

### Visualizando textos

Na aba "Textos", você verá cards com os seguintes elementos:
- **ID e Chave**: Identificadores do texto
- **Conteúdo**: Área de texto com o conteúdo atual
- **Última Atualização**: Data e hora da última modificação

### Editando um texto

Para editar um texto de seção:

1. Localize o texto desejado na lista
2. Modifique o conteúdo na área de texto
3. Clique no botão "Salvar Alterações"

Observação: Você pode utilizar formatação básica de texto, como parágrafos, mas não é suportada formatação HTML avançada.

## Boas Práticas

- **Verifique os dados**: Antes de salvar, certifique-se de que os valores estão corretos
- **Seja conciso**: Textos muito longos podem prejudicar o layout do site
- **Mantenha a consistência**: Preserve o estilo e tom de voz do conteúdo existente

## Suporte

Em caso de dúvidas ou problemas, entre em contato com a equipe de suporte técnico.
